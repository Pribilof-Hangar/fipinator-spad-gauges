# Boeing style

**Made for fun, not tested on a FIP yet.** Testers welcome: if something's off, fix it in your fork and share it.

![Boeing style](../../previews/Boeing%20style.png)

2 gauges. **Download this set: [Boeing style.zip](../../downloads/Boeing%20style.zip)**, unzip it, and add the folder in SPAD.neXt (see the [front page](../../README.md)). Or get every set at once: [All gauges.zip](../../downloads/All%20gauges.zip).
