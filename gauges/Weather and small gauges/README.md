# Weather and small gauges

**Made for fun, not tested on a FIP yet.** Testers welcome: if something's off, fix it in your fork and share it.

![Weather and small gauges](../../previews/Weather%20and%20small%20gauges.png)

3 gauges. **Download this set: [Weather and small gauges.zip](../../downloads/Weather%20and%20small%20gauges.zip)**, unzip it, and add the folder in SPAD.neXt (see the [front page](../../README.md)). Or get every set at once: [All gauges.zip](../../downloads/All%20gauges.zip).
