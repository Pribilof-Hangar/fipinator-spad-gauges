# Classic single

**Made for fun, not tested on a FIP yet.** Testers welcome: if something's off, fix it in your fork and share it.

![Classic single](../../previews/Classic%20single.png)

16 gauges. **Download this set: [Classic single.zip](../../downloads/Classic%20single.zip)**, unzip it, and add the folder in SPAD.neXt (see the [front page](../../README.md)). Or get every set at once: [All gauges.zip](../../downloads/All%20gauges.zip).
