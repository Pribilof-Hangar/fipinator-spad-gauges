# Dual jet

**Made for fun, not tested on a FIP yet.** Testers welcome: if something's off, fix it in your fork and share it.

![Dual jet](../../previews/Dual%20jet.png)

13 gauges. **Download this set: [Dual jet.zip](../../downloads/Dual%20jet.zip)**, unzip it, and add the folder in SPAD.neXt (see the [front page](../../README.md)). Or get every set at once: [All gauges.zip](../../downloads/All%20gauges.zip).
