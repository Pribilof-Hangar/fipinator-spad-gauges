# Classic twin

**Made for fun, not tested on a FIP yet.** Testers welcome: if something's off, fix it in your fork and share it.

![Classic twin](../../previews/Classic%20twin.png)

17 gauges. **Download this set: [Classic twin.zip](../../downloads/Classic%20twin.zip)**, unzip it, and add the folder in SPAD.neXt (see the [front page](../../README.md)). Or get every set at once: [All gauges.zip](../../downloads/All%20gauges.zip).
