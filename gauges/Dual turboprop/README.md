# Dual turboprop

**Partly flown with**: some of these were flown with in FIPinator Live (the SPAD.neXt versions are made from the same files), not all of them. Testers welcome: if something's off, fix it in your fork and share it.

![Dual turboprop](../../previews/Dual%20turboprop.png)

8 gauges. **Download this set: [Dual turboprop.zip](../../downloads/Dual%20turboprop.zip)**, unzip it, and add the folder in SPAD.neXt (see the [front page](../../README.md)). Or get every set at once: [All gauges.zip](../../downloads/All%20gauges.zip).
