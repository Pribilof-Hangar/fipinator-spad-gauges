# Gear, flaps and trim

**Made for fun, not tested on a FIP yet.** Testers welcome: if something's off, fix it in your fork and share it.

![Gear, flaps and trim](../../previews/Gear,%20flaps%20and%20trim.png)

3 gauges. **Download this set: [Gear, flaps and trim.zip](../../downloads/Gear,%20flaps%20and%20trim.zip)**, unzip it, and add the folder in SPAD.neXt (see the [front page](../../README.md)). Or get every set at once: [All gauges.zip](../../downloads/All%20gauges.zip).

| Gauge | | About it |
|---|---|---|
| **Flaps (generic)** | <img src="../../previews/Gear,%20flaps%20and%20trim/Flaps%20%28generic%29.png" width="200" alt="Flaps (generic)"> | Flap position indicator, 0 to 40 degrees, marks at 10, 20, 30, 40. |
| **Landing gear** | <img src="../../previews/Gear,%20flaps%20and%20trim/Landing%20gear.png" width="200" alt="Landing gear"> | Gear lights per leg (green DOWN, red IN TRANSIT, dark UP) and the gear handle. S1 moves the gear (GEAR_TOGGLE). |
| **Trim** | <img src="../../previews/Gear,%20flaps%20and%20trim/Trim.png" width="200" alt="Trim"> | Elevator, rudder and aileron trim. S1-S3 pick which trim the knobs set (right knob fine, left knob faster). |

Free and open source (AGPL-3.0), made from scratch. See the [front page](../../README.md).
