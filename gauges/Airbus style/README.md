# Airbus style

**Made for fun, not tested on a FIP yet.** Testers welcome: if something's off, fix it in your fork and share it.

![Airbus style](../../previews/Airbus%20style.png)

6 gauges. **Download this set: [Airbus style.zip](../../downloads/Airbus%20style.zip)**, unzip it, and add the folder in SPAD.neXt (see the [front page](../../README.md)). Or get every set at once: [All gauges.zip](../../downloads/All%20gauges.zip).

| Gauge | | About it |
|---|---|---|
| **Autobrake (Airbus style)** | <img src="../../previews/Airbus%20style/Autobrake%20%28Airbus%20style%29.png" width="200" alt="Autobrake (Airbus style)"> | Airbus-style autobrake: LO, MED, MAX on S1-S3 (SET_AUTOBRAKE_CONTROL 1, 2, 3; to check per plane), the chosen one lit. |
| **Engines (Airbus style)** | <img src="../../previews/Airbus%20style/Engines%20%28Airbus%20style%29.png" width="200" alt="Engines (Airbus style)"> | Airbus A320neo: N1 and EGT dials and N2 and fuel flow numbers for every engine on one screen, Airbus ECAM style, fuel flow in kg/h. Limits: EASA TCDS E.110 (CFM LEAP-1A). |
| **FCU (Airbus style)** | <img src="../../previews/Airbus%20style/FCU%20%28Airbus%20style%29.png" width="200" alt="FCU (Airbus style)"> | Airbus FCU-style autopilot display: speed, heading, altitude and vertical speed in orange digits. S1-S4 pick which one the knobs set (left knob faster); S6 AP1 on/off with its light. |
| **Flaps (Airbus style)** | <img src="../../previews/Airbus%20style/Flaps%20%28Airbus%20style%29.png" width="200" alt="Flaps (Airbus style)"> | Airbus ECAM-style slats (S) and flaps (F) with moving markers and the lever position: 0, 1, 1+F, 2, 3, FULL. Knobs move the flap lever. |
| **Landing gear (Airbus style)** | <img src="../../previews/Airbus%20style/Landing%20gear%20%28Airbus%20style%29.png" width="200" alt="Landing gear (Airbus style)"> | Airbus ECAM-style gear: a triangle per leg (green down, red moving, dark up) and the lever position. S1 moves the gear. |
| **Speedbrake (Airbus style)** | <img src="../../previews/Airbus%20style/Speedbrake%20%28Airbus%20style%29.png" width="200" alt="Speedbrake (Airbus style)"> | Airbus-style speedbrake lever position (RET to FULL) and GND SPLRS ARMED light. S1 arms or disarms the ground spoilers. |
