# Cessna 404 Titan

**Made for fun, not tested on a FIP yet.** Testers welcome: if something's off, fix it in your fork and share it.

![Cessna 404 Titan](../../previews/Cessna%20404%20Titan.png)

7 gauges. **Download this set: [Cessna 404 Titan.zip](../../downloads/Cessna%20404%20Titan.zip)**, unzip it, and add the folder in SPAD.neXt (see the [front page](../../README.md)). Or get every set at once: [All gauges.zip](../../downloads/All%20gauges.zip).
