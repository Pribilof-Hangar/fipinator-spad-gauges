# Autopilot and radios

**Made for fun, not tested on a FIP yet.** Testers welcome: if something's off, fix it in your fork and share it.

![Autopilot and radios](../../previews/Autopilot%20and%20radios.png)

3 gauges. **Download this set: [Autopilot and radios.zip](../../downloads/Autopilot%20and%20radios.zip)**, unzip it, and add the folder in SPAD.neXt (see the [front page](../../README.md)). Or get every set at once: [All gauges.zip](../../downloads/All%20gauges.zip).

| Gauge | | About it |
|---|---|---|
| **Autopilot settings** | <img src="../../previews/Autopilot%20and%20radios/Autopilot%20settings.png" width="200" alt="Autopilot settings"> | Autopilot speed, heading, altitude and vertical speed. S1-S4 pick which one the knobs set (left knob faster); S6 turns the autopilot on or off. |
| **Radios (COM1 - NAV1)** | <img src="../../previews/Autopilot%20and%20radios/Radios%20%28COM1%20-%20NAV1%29.png" width="200" alt="Radios (COM1 - NAV1)"> | COM1 and NAV1 active and standby frequencies. S1/S2 pick the radio the knobs tune (left knob MHz, right knob kHz); S3/S4 swap active and standby. |
| **Transponder** | <img src="../../previews/Autopilot%20and%20radios/Transponder.png" width="200" alt="Transponder"> | Transponder code and mode. S1 picks the first two digits, S2 the last two: the left knob sets the left digit of the pair, the right knob the right one. |

Free and open source (AGPL-3.0), made from scratch. See the [front page](../../README.md).
